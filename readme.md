
# 🌍 IP Geolocator

Geolocalização simples de endereços IP via API, direto no navegador, com **HTML**, **CSS** e **JavaScript**.

## ✨ Funcionalidades

- Consulta de geolocalização a partir de um endereço IP
- Exibição das informações retornadas em formato de lista (rótulo e valor)
- Estado vazio com a mensagem "No Results"
- Interface simples e direta, em uma única página
- Ícones com **Font Awesome**

## 🛠️ Tecnologias

| Tecnologia | Uso |
| --- | --- |
| HTML5 | Estrutura da página |
| CSS3 | Estilização da interface |
| JavaScript | Consulta à API e renderização dos resultados |
| [Font Awesome](https://fontawesome.com/) | Ícones (carregado via CDN) |

## 📁 Estrutura do projeto

```
IP-Geolocator/
├── index.html    # Estrutura da página
├── main.js       # Lógica de geolocalização
└── styles.css    # Estilos da interface
```

## 🚀 Como executar

### Pré-requisitos

- Um navegador moderno
- Conexão com a internet (para a API e o Font Awesome)

### Instalação

```bash
# 1. Clone o repositório
git clone https://github.com/higordday/IP-Geolocator.git

# 2. Acesse a pasta do projeto
cd IP-Geolocator
```

### Execução

Não é necessário instalar dependências. Abra o arquivo `index.html` no navegador.

## 💡 Como usar

1. Digite um endereço IP no campo **IP Address**
2. Clique em **Geolocate**
3. Veja as informações de localização na lista de resultados
